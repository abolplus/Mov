# سایت فیلم اشتراکی

نسخه کاملاً Front-End برای GitHub Pages.

## اجرا
فایل‌ها را داخل یک Repository قرار دهید و از:
`Settings → Pages`
سایت را روی branch اصلی فعال کنید.

## مدیریت
رمز پنل مدیریت:
`abolkos`

## کد اشتراک
- هر کد فقط یک بار استفاده می‌شود.
- تایمر ۱ ساعته دقیقاً از اولین ورود کاربر شروع می‌شود.
- اطلاعات در `localStorage` مرورگر ذخیره می‌شوند.
- برای تست، کد `ABCD123456` به صورت نمونه ایجاد شده است.

## افزودن فیلم
از پنل مدیریت لینک مستقیم فایل ویدیو را وارد کنید، یا فایل `movies-data.js` را ویرایش کنید.

> این نسخه برای GitHub Pages است؛ بنابراین امنیت واقعی سمت سرور ندارد و اطلاعات localStorage قابل تغییر توسط کاربر است.


## نمایش فیلم در منوی اصلی
وقتی مدیر از پنل یک فیلم اضافه می‌کند، اطلاعات آن در localStorage ذخیره شده و فیلم بلافاصله در `home.html` نمایش داده می‌شود.

## لینک فیلم در پنل
لینک مستقیم فیلم در پنل مدیریت قابل کلیک است. با اولین کلیک مدیر، زمان مشاهده ثبت می‌شود و گزینه «حذف» تا ۵ دقیقه در دسترس است؛ پس از ۵ دقیقه گزینه حذف خودکار ناپدید می‌شود.


### تغییرات رابط
- صفحه پروفایل حذف شد.
- مدیریت با دکمه سه‌خط در بالا سمت چپ باز می‌شود.
- نوار پایین فقط «منو اصلی» را نشان می‌دهد.
- فرم ورود کد اشتراک به‌صورت شناور و وسط صفحه قرار گرفت.
- برای کد اشتباه پیام «کد اشتباه است.» نمایش داده می‌شود.
- فیلم و لینک پس از ۵ دقیقه حذف نمی‌شوند؛ فقط گزینه حذف از پنل مدیریت ناپدید می‌شود.


### آخرین تغییرات
- تمام فیلم‌های موجود در منوی اصلی نمایش داده می‌شوند، نه فقط آخرین فیلم.
- کنترل دانلود و Picture-in-Picture در ویدیو غیرفعال شده و راست‌کلیک روی ویدیو بسته شده است. توجه: در سایت کاملاً فرانت‌اندی، جلوگیری ۱۰۰٪ از ذخیره/دریافت ویدیو از طریق ابزارهای مرورگر ممکن نیست.
